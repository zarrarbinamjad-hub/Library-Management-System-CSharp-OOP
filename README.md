# Library Management System

This is a beginner-friendly Library Management System developed using C# as part of my Object-Oriented Programming (OOP) practice. This console-based application allows a library to manage books and perform different operations such as adding books, displaying all books, searching for a book by ID, updating book prices, deleting books, counting total books, finding the most expensive book, calculating the total price of books, and displaying issued and available books. Through this project, I practiced important C# and OOP concepts including classes, objects, constructors, properties, methods, arrays, loops, conditional statements, Boolean values, and basic CRUD operations. The project helped me improve my understanding of how different classes can work together to create a simple real-world application and strengthened my problem-solving and programming skills. In the future, I plan to improve this project by adding user input, menu-based navigation, validation, library members, borrowing history, file storage, and SQL Server database integration using Entity Framework Core.
